# 008 — Групповые чаты

## Контекст

PDR: `specs/pdr/008-group-chats.md`. Нужны чаты с несколькими участниками без ломания 1:1.

## Цель

Пользователь создаёт группу с названием и несколькими участниками; все участники пишут и видят сообщения.

## User stories

- Как пользователь, я создаю группу, указываю название и выбираю ≥2 участников.
- Как участник группы, я вижу её в списке диалогов и переписываюсь в ленте.
- Как пользователь, я по-прежнему создаю личный чат 1:1.

## Требования

### Must

- [x] Колонки `conversations.type` (`direct`|`group`, default `direct`) и `conversations.title` (nullable)
- [x] `POST /api/conversations` с `{ user_id }` — прежнее поведение 1:1 (`type=direct`)
- [x] `POST /api/conversations` с `{ title, user_ids: number[] }` — группа: title 1–100, `user_ids` 2–20 уникальных id ≠ себя, все существуют
- [x] Создатель всегда участник группы
- [x] Сериализация: `type`, `title`, `members_count`; для `direct` — `peer`; для `group` — `peer: null`, `title`, краткий `members: [{id,name,avatar_url}]` (до 5 для превью)
- [x] UI: в диалоге нового чата режим «Личный» / «Группа»
- [x] Список и шапка ленты показывают название группы и число участников
- [x] Доступ к messages/reactions только участникам (как сейчас)

### Should

- [x] В ленте группы у чужих сообщений видно имя автора (уже есть)

### Must not

- [x] Не ломать создание 1:1
- [x] Не требовать title для direct

## UX / UI

- Toggle/tabs в NewChatDialog
- Группа: TextField названия + чекбоксы пользователей (тот же список/поиск)
- Кнопка создать disabled, пока нет title или <2 выбранных

## Технические заметки

- Миграция additive; существующие rows → `direct`
- `Conversation::isGroup()`, `isDirect()`
- WS channel без изменений (по participant)

## Критерии приёмки

1. Группа из создателя + 2 пользователей создаётся и видна всем троим
2. 1:1 по `user_id` работает как раньше (без дублей)
3. `user_ids` с 1 элементом / пустым title → 422
4. Посторонний не читает групповой чат (403)

## Вне скоупа

- Управление составом после создания, роли, аватар группы
