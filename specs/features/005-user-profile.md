# 005 — Профиль пользователя

## Контекст

Пользователю нужно менять свои данные и фото без админки и правок в БД.

## Цель

Авторизованный пользователь открывает раздел профиля, обновляет имя/email/пароль и загружает или удаляет аватар.

## User stories

- Как пользователь, я открываю профиль из шапки и вижу свои текущие данные.
- Как пользователь, я меняю имя и email.
- Как пользователь, я меняю пароль, указав текущий.
- Как пользователь, я загружаю или удаляю фото профиля.
- Как пользователь, я вижу аватары собеседников в списке диалогов и поиске.

## Требования

### Must

- [ ] Миграция: `users.avatar_path` (nullable string)
- [ ] `PATCH /api/me` — `name`, `email`; при смене пароля: `password`, `password_confirmation`, `current_password`
- [ ] `POST /api/me/avatar` — multipart `avatar` (jpeg/png/webp/gif, ≤ 2 MB)
- [ ] `DELETE /api/me/avatar` — удаление файла и сброс `avatar_path`
- [ ] User JSON включает `avatar_url` (null или публичный `/storage/...`)
- [ ] Страница `/profile` (MUI): форма + загрузка/удаление аватара + ошибки валидации
- [ ] Ссылка «Профиль» и аватар в AppBar
- [ ] Redux: `updateProfile`, `uploadAvatar`, `deleteAvatar`
- [ ] Аватары в списке диалогов, поиске пользователей, ленте сообщений

### Should

- [ ] При смене аватара старый файл удаляется с диска

### Must not

- [ ] Обрезка/редактор аватара в браузере
- [ ] Смена email без проверки уникальности

## UX / UI

- `/profile`: аватар, поля name/email, блок смены пароля, кнопки сохранить / загрузить / удалить фото
- Ошибки API под полями или алертом
- В шапке клик по имени/аватару → профиль

## Технические заметки

- Диск `public`, путь `avatars/{userId}.{ext}`, `storage:link`
- FormData на клиенте без принудительного `Content-Type: application/json`

## Критерии приёмки

1. `PATCH /api/me` обновляет name/email; неверный `current_password` → 422
2. Загрузка аватара возвращает user с `avatar_url`; повторная загрузка заменяет файл
3. Удаление аватара → `avatar_url: null`
4. UI профиля сохраняет данные и отображает новое фото в шапке и списках

## Вне скоупа

- Email verification при смене email
- CDN, внешнее хранилище
