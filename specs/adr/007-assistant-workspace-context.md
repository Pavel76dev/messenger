# ADR-007: Роутер LLM + серверная сборка workspace; авто-ASR при save

- **Статус:** accepted
- **Дата:** 2026-10-21
- **Контекст:** feature `017-assistant-workspace-context`

## Контекст

Ассистенту иногда нужны переписки, текст документов и транскрипты аудио.
Всегда слать полный дамп — дорого и шумит на бытовых репликах.
Ждать ASR в момент ответа — плохой UX, если записи копятся заранее.

## Решение

1. **Авто-ASR при сохранении клипа** (`POST /api/audio-clips`): сразу `pending` +
   фон Job/CLI как в ADR-006 / feature 014. К моменту задач у ассистента текст
   обычно уже есть. Ручной transcribe — для retry.

2. **Двухшаговый ответ бота** в `GenerateAiReply`:
   - **Router:** короткий `LlmClient::chat` → JSON `{ "need_workspace": bool }`
     (по запросу пользователя; опционально краткий каталог источников без полных тел).
   - Если `false` — один reply-вызов как в 012 (история чата с ботом).
   - Если `true` (или parse fail) — `AssistantWorkspaceContext` собирает текстовый
     пакет → второй reply-вызов с контекстом.

3. В модель уходит **только текст** (сообщения, extract вложений, `transcript_text`).
   Нет ожидания ASR внутри reply-job; клипы не-`done` помечаются в каталоге.

4. **Кэш extract** на `message_attachments`; капы config; ACL по participant/owner.

5. **Без RAG и без tools API** в v1: роутер — обычный chat + JSON, не function calling.

6. Парсинг документов — на сервере приложения (PHP и/или CLI в репо).

## Альтернативы

1. **Всегда полный workspace** — отвергнуто продуктом (ИИ сама решает по запросу).
2. **Ждать ASR в reply-job** — отвергнуто: транскрибируем по мере записи в фоне.
3. **Tool-calling** — гибче, но нестабильно на локальном api-llm; отложено.
4. **Векторный RAG** — отдельно, при росте корпуса.
5. **Только keyword-роутер без LLM** — проще, но хуже на перефразах; продукт хочет решение ИИ.

## Последствия

- Плюсы: дешёвые бытовые ответы; транскрипты «подогреты»; один ACL-путь; reuse 012/014.
- Минусы: +1 LLM-вызов на каждое сообщение боту; ошибки роутера (митигация: fail-open → context on);
  клипы ещё в pending видны ассистенту как пробел.
- Эволюция: UI источников, RAG, tools, расширенные форматы.
