# Vibes: Messenger

## Продуктовое ощущение

Простой учебный чат 1:1 в браузере: быстро открыл диалог, написал, увидел ответ.
Без «корпоративной тяжести» и без лишних экранов. Код и поведение читаются через спеки.

## UX-вайб

- Чистый список диалогов + лента сообщений (MUI, без сторонних UI-библиотек)
- Отклик: свои действия сразу; чужие — через realtime (сначала polling, затем WebSocket)
- Реакции — нативные эмодзи браузера, без внешних иконок CDN
- Ошибки понятные, без технического шума в UI

## Жёсткие рамки

- Один домен OpenServer: Laravel API + React SPA
- Sanctum Bearer tokens
- Не цели MVP: E2E-шифрование медиа, нативные клиенты; роли в группах — позже
- Звонки: WebRTC через self-hosted LiveKit (веб; нативные клиенты — отдельный эпик)
- PHP 8.1+, минимальный дифф в PR/коммитах агента

## Сигналы успеха

- Два пользователя переписываются end-to-end
- Реакции видны без F5 (realtime или короткий polling-fallback)
- Новая фича появляется только после SDLS-артефактов
