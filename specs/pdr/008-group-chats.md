# PDR: Групповые чаты

## Проблема

Сейчас только 1:1. Нельзя создать переписку на несколько участников.

## Решение (одним абзацем)

Добавляем тип диалога `group` с названием и списком участников (≥2 кроме создателя);
личный чат остаётся как `direct` с прежним контрактом `user_id`.

## Скоуп

### In

- Создание группы: название + мультивыбор пользователей
- Список/шапка: название группы и число участников
- Сообщения, реакции, вложения, WS — как у обычного диалога (участник = доступ)
- Существующие диалоги = `direct`

### Out

- Роли (админ), кик/инвайт после создания
- Аватар группы, описание
- Объединение дубликатов групп
- Каналы / broadcast-only

## Пользовательские потоки

1. «Новый чат» → вкладка «Группа» → название → отметить ≥2 человек → создать.
2. Группа появляется в списке слева; открывается лента.
3. Личный чат создаётся как раньше (один пользователь).

## Решения и компромиссы

| Вопрос | Решение | Почему |
|--------|---------|--------|
| Минимум участников | создатель + ≥2 других | иначе это 1:1 |
| Максимум | 20 других в создании | как лимит поиска users |
| Дедуп групп | не ищем «ту же» группу | проще MVP |
| Поле title | обязательно для group | иначе пустой заголовок |

## Риски

- UI списка должен не ломаться на `peer: null` у групп
