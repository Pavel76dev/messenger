# PDR: Аудио-фрагменты

## Проблема

Нельзя быстро записать короткий голосовой фрагмент (свой mic) вне звонка и во время ВКС,
сохранить в личную библиотеку или отправить в чат.

## Решение (одним абзацем)

Кнопка записи рядом со скрепкой: toggle (кнопка «западает») вне звонка и во время ВКС.
После стопа — «Сохранить» (серверная библиотека пользователя) или «Отправить в чат»
(вложение 006). Список сохранённых — play / delete. Только свой микрофон.

## Скоуп

### In

- Кнопки Mic + Library в composer; дубль Mic в CallOverlay
- Toggle запись (западает / отжата)
- Диалог Сохранить / Отправить / Отмена
- Серверная библиотека `audio_clips` (ADR-005)
- Отправка через `files[]` API 006

### Out

- Remote mix / запись всей конференции
- Отправка из библиотеки в чат (v1)
- Press-and-hold
- IndexedDB как основное хранилище
- Транскрипция / редактор

## Пользовательские потоки

1. Клик Mic → запись → клик → диалог → Отправить или Сохранить
2. То же во время ВКС из CallOverlay
3. Library → список (дата-время) → Play / Удалить

## Решения и компромиссы

| Вопрос | Решение | Почему |
|--------|---------|--------|
| Хранение | Сервер `audio_clips` | Запрос продукта; доступ с разных устройств |
| Звук | Только local mic | Явно |
| UX | Toggle везде | «Западает» во время связи |
| Send из library | Вне v1 | Упрощение |
