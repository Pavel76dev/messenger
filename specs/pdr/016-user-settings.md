# PDR: Настройки пользователя

## Проблема

Промпт извлечения задач из транскрипта захардкожен. Пользователю нужна возможность править его; позже появятся другие персональные опции.

## Решение

Персональная панель настроек: реестр известных ключей в конфиге (с дефолтами), значения в БД на пользователя. UI рендерит поля по схеме — новые ключи добавляются в конфиг без смены модели данных.

## Скоуп

### In

- Таблица key/value на пользователя
- `GET/PATCH /api/me/settings`
- Страница «Настройки» (маршрут)
- Ключ(и) промпта extract-tasks; extract читает настройки владельца клипа
- Сброс поля к дефолту

### Out

- Админские глобальные настройки
- Шаринг настроек между пользователями

## Решения

| Вопрос | Решение |
|--------|---------|
| Хранение | `user_settings` (user_id, key, value) |
| Схема | `config/user_settings.php` — definitions |
| UI | `/settings`, ссылка из профиля |
